## 🌌 Overview

**Chapter Us** is an interactive, immersive web experience built to celebrate and safeguard an unbreakable bond. From nostalgic raw mango conversations to late-night honest reflections, this platform acts as an eternal digital time-capsule featuring music, photos, untold letters, and shared chronicles.

> 🔗 **Live Website**: [https://manthansahu20.github.io/Chapter-Us-Our-Little-Universe-/](https://manthansahu20.github.io/Chapter-Us-Our-Little-Universe-/)

---

## ✨ Features & Sections

- ⏳ **Dynamic Memory Counter**: Real-time counter capturing the journey unfolding since **April 2, 2025**.
- 🎵 **Integrated Soundtrack Player**: Custom curated audio player bringing memories alive with music.
- 🌌 **Cosmic Interactive Canvas**: Background starfield and fluid ambient effects creating a celestial aesthetic.
- 📸 **Visual Memory Archive**: A gallery preserving spontaneous and treasured snapshots.
- 💌 **Things I Never Said (Letters)**: An intimate corner holding heartfelt affirmations and unspoken letters.
- 💬 **The Conversations**: Snippets of witty banter, daily check-ins, and meaningful chats.
- 🕊️ **Little Things**: The subtle, quiet nuances and comfort that define an irreplaceable bond.
